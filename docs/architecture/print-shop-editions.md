# Print-Shop Editions — Plain Dharma

*Last updated: 2026-09-17*

## Overview

The print-shop editions system generates three hand-out-ready PDFs (interior + cover sheet per size) that copy shops can print at 100% without measuring or guessing. All three hold the same 12pt Garamond Libre typeface across different paper sizes — the type is **not** scaled, only the trim size changes. This keeps narrow editions readable when printed and handed on; shrinking the type would defeat the purpose of having them.

Each edition produces two files:
- **Interior** — pages in reading order, black & white, on copy paper. Not imposed; the shop's driver handles n-up and duplex.
- **Covers** — 2-page front/back sheet (color, on card stock). Includes crop marks for the trim.

The three sizes are offered in order on `/print`: **A5** (table), **B6** (pocket, tiling exception), **A6** (shirt-pocket).

## Data flow

1. **Edition definition** — `scripts/build-printshop-pdf.ts` defines a static `EDITIONS` array (A5, B6, A6) with trim size, margins, chapter/section font sizes, typeset tuning (`headerTuning`, `tocTuning`, `typesetTuning`). This is the system of record; everything else derives from it.

2. **Preamble generation** — For each edition, the script reads `scripts/templates/pdf-preamble-printshop.tex`, substitutes tokens from the edition entry, and writes a per-edition preamble to `dist/printshop/work/`.

3. **Book markdown** — Shared MDX sources (six suttas, preface, closing, colophon) are converted to a single markdown by `buildBookMarkdown` from `scripts/lib/book-source.ts`. Illustrations are centered via `centerImages()` (wrapping bare `![...](...)`in a center block).

4. **PDF generation** — `pandoc` reads the book markdown, includes the per-edition preamble, and calls `xelatex` to produce a PDF. Pages are padded to a multiple of `pagesPerSheet` (A5: 4 per sheet, B6: 4 per sheet, A6: 8 per sheet) using `padPagesTex()`, which injects a "Pass it on" card on the first padded page (if any) followed by blank pages.

5. **Spec measurement** — After PDF generation, the script measures file sizes and page counts and writes them to `printshop-spec.json`, along with the sheet count (pages ÷ pagesPerSheet, rounded up).

6. **Publishing** — Both the interior PDF and the cover sheet are published to `public/downloads/` with names like `plain-dharma-printshop-a5.pdf`, `plain-dharma-printshop-a5-covers.pdf`.

7. **Web gating** — `printshop.ts` reads the committed `printshop-spec.json` and filters `PRINTSHOP_EDITIONS` to only entries whose files exist in the version map (via `hasAsset()` checking the CDN). The `/print` page only offers editions whose PDFs have been uploaded.

8. **Spec sheet rendering** — `PrintSpecSheet.tsx` formats the spec for one edition, substituting placeholders with values from `editionVars()` and language-specific strings from the `CUT` and `FIT` tables.

## Important patterns

**Three editions, no shrinking the type.** All three hold 12pt Garamond Libre. A5 is the table edition (114mm measure, ~62 chars/line, 52 pages, 13 sheets). B6 is the pocket edition (98mm measure, ~53 chars/line, 60 pages, 15 sheets) — narrower but still readable, and it does NOT tile A4 (this is deliberate and critical — see "A4 tiling rule" below). A6 is the shirt-pocket edition (83mm measure, ~45 chars/line, 72 pages, 9 sheets). The narrow editions run longer because the type is fixed; they offset this by stacking more per sheet (A6 fits 8 pages per duplex A4 sheet vs A5's 4).

**Shared typeset constants.** The two narrow trims (B6, A6) both use `NARROW_TYPESET`, `NARROW_HEADER`, and `NARROW_TOC` — shared LaTeX that handles microtype protrusion, runs down running heads until they fit, and prevents wrapping with hyphenation in the table of contents. A5 sets none of these; the class defaults already fit its measure. This is measured rather than tuned, so a trim between A5 and A6 can take the constants unchanged.

**Frozen A5 pagination.** A5 is published with a fixed page count (52 pages, 13 sheets). Its pagination must not move. Every other build script rebuilds all three, but A5's layout is locked to keep print orders valid. If you change A5's margins or type size you MUST verify the page count stays 52, or orders printed before the change will bind wrong.

**Heading geometry trap.** Running heads occupy space ABOVE the top margin, not inside it. The formula is: trim edge → headsep → headheight → textheight. On A6 with top=10mm and the class's 18pt headsep, the math came out to -1.3mm, printing the head off the top of the page. Fixing this required dropping headsep to 8pt (the head is one size down here anyway) and trading 4mm between top and bottom margins. This kept textheight at 126mm so pagination didn't move. The pattern: when adding a header to a narrow trim, measure from the edge in the preamble comment.

**Padding to whole sheets.** Because pages are n-up duplex, they must land on sheet boundaries (4 for A5, 4 for B6, 8 for A6). If the page count isn't a multiple, blank pages are added. The first padded page is spent on a "Pass it on" card (the one page in the edition that costs nothing to use); the rest stay blank. If an edition already hits a sheet boundary, no card appears. This rule lives in `padPagesTex()` and the card text in `PASS_IT_ON`.

**{cut} and {fit} placeholders in copy.** The spec sheet has a row saying "Print {up}-up on A4, double-sided, then {cut}." The placeholder is necessary because A5 says "cut in half" (2 per sheet), B6 says "trim to marks" (non-A size, no fold), and A6 says "cut into quarters" (4 per sheet). Written into the sentence, the B6 version would silently tell a shop that can fold A4. Placeholders solve this with the `CUT` table. The `FIT` row has the same pattern: A5 and A6 fit A4 exactly, B6 does not. Kept in a table so the B6 spec sheet tells the truth.

**A4 tiling rule — and why B6 breaks it.** A5 and A6 are exact fractions of A4, which is why the shop prints them by halving or quartering a sheet by eye (no measurement, no drift). B6 is 125×176mm. Two side by side is 250mm against A4's 210mm width; two stacked is 352mm against its 297mm height. Two fit only turned sideways (176×250 inside 210×297), which leaves a border on every sheet — roughly 30% of the paper thrown away — and means the shop must cut to marks rather than halve by eye. A copy therefore takes 15 A4 sheets against A5's 13, for eight fewer pages.

This is a cost the edition accepts, **not** a design goal. B6 is the geometric mean of A5 and A6 (√(105×148)=125, √(148×210)=176), which is precisely what makes it a good size to hold and an irrational fraction of an A sheet — the property that makes it pleasant is the same one that makes it wasteful. It was added because it is the classic pocket-paperback trim and reads far better than A6 (~53 chars/line against ~45), with the tiling penalty understood and accepted. `FIT[lang]["b6"]` states this on the spec sheet so no shop halves a sheet and produces the wrong booklet.

**Blank pages don't carry running heads.** A blank verso that opens a chapter was stamped with a running head and folio by the book class, which reads as a misprint. `NARROW_TYPESET` redefines `\cleardoublepage` to insert a blank verso with `\thispagestyle{empty}`, stripping both the head and page number.

**Table of contents entries don't stretch.** The class's `\@tocrmarg` forced wrapped TOC entries (e.g., "3. The Buddha's Third Talk: The Fire Sermon") to justify on their first line, leaving stretched interword space. `NARROW_TOC` changes this to `\@tocrmarg plus 1fil`, letting wrapped lines end ragged (which is how a title should break). A corresponding patch to `\l@chapter` makes the page number stay hard right via `\hfill` so only non-final lines are ragged.

## Gotchas

- **B6 does not tile A4.** Unlike A5 (exactly 2 per sheet) and A6 (exactly 4 per sheet), B6 must be cut to marks, and wastes about 30% of every sheet — 15 A4 sheets per copy against A5's 13. This is an accepted cost of the trim, not a feature. Do not "fix" it by scaling B6 to fit A4: that would change the finished size and defeat the point.

- **A5 pagination is frozen.** The currently published spec lists A5 at 52 pages, 13 sheets. If a future edit changes the page count, print orders placed before the change will bind wrong (different signature arrangement). A5's margins and type are locked. To change A5: verify the new page count, update the spec in git, and announce the change to anyone who might have live orders.

- **Running heads occupy space above the top margin.** The formula for geometry is: edge → headsep → headheight → textheight. On narrow trims with tight top margins, this can result in negative space (the head printing off-page). A6 solved this by dropping headsep from 18pt to 8pt and redistributing margin space, keeping textheight at 126mm so pagination stayed. If you add a header to a narrow trim, check the math.

- **Padding card appears only on padded copies.** The "Pass it on" card fills the first blank page added to make the page count a multiple of `pagesPerSheet`. If an edition hits that multiple exactly (A5 does), no card appears. This is correct behavior — it's only a gift-tag if there was a blank page to begin with.

- **Two XeLaTeX passes required.** TikZ's `current page` node (used for positioning covers) is only available on the second pass. `scripts/render-covers.ts` runs xelatex twice.

- **Illustrations are grayscale on the interior.** The shop prints the interior on B&W copy machines. Illustrations are converted to grayscale at 1200px, then flattened on white (to clear any alpha residue from the `transparentize` pass). See `prepareIllustration()` in the build script.
